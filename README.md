> Engineering API infrastructure for the BetonBaz ecosystem.

This repository contains backend/API tooling supporting concrete and engineering software.

## Role

```text
Engineering applications
        ↓
    betonbaz-api
        ↓
  structured services
        ↓
 data / integrations
```

## Engineering principles

- Keep domain data explicit and traceable.
- Separate API concerns from UI concerns.
- Validate inputs at system boundaries.
- Prefer deterministic calculations for engineering logic.
- Do not silently invent missing values.
- Keep credentials and production access outside source control.
